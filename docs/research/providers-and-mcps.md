# Providers and official MCP servers: research for the "ship your app" plugin

Researched 2026-10-03. Every fact below comes from a page opened in this session, and the URL is next to it.
- **(unverified)** means the claim comes from a third-party page or search snippet, or wasn't checked here.
- **CLI names** (`vercel`, `netlify`, `wrangler`, `firebase`, `amplify`, `render`, `flyctl`/`fly`, `railway`) come from general knowledge, not the linked pages, so treat them as (unverified). The only exceptions are `fly mcp server`, `railway setup agent`, `stripe agent setup`, `npx neon@latest init`, `npx convex@latest mcp start`, and `npx firebase-tools@latest mcp`, which the linked docs confirm.
- Prices are in USD and change often. The plugin should re-fetch the pricing URL before quoting a price to a user.

## Surprises / gotchas for the plugin's logic

1. **Stripe doesn't support Colombia** (only BR and MX in Latin America), and **Stripe Managed Payments** (MoR) only accepts businesses in the US, CA, Europe, AU, HK, JP, SG. Colombian sellers need Paddle, Polar, Creem, Lemon Squeezy, Mercado Pago, PayPal, or a Stripe Atlas US entity.
2. **Lemon Squeezy is being folded into Stripe Managed Payments** (2026 banner on the pricing page). Since Colombia isn't eligible for Managed Payments, Lemon Squeezy is a risky long-term default for Colombian sellers.
3. **Stripe MCP drops non-Agent API keys on 2026-10-31.** Use OAuth or Agent keys only.
4. **Firebase MCP is now `npx firebase-tools@latest mcp`**, not `firebase experimental:mcp`.
5. **awslabs `cdk-mcp-server` (yanked from PyPI), `terraform-mcp-server`, `cfn-mcp-server`, and `ccapi-mcp-server` are deprecated.** Use `aws-iac-mcp-server` and HashiCorp's Terraform MCP. AWS also tells you to swap `aws-api-mcp-server` and `aws-knowledge-mcp-server` for the GA **AWS MCP Server**.
6. **Vercel Hobby is non-commercial only**, so a paying product on $0 should go on Cloudflare Workers.
7. **Fly.io has no free tier**, and **Render's free Postgres is deleted after 30 days**. Don't recommend either as a "$0 forever" database.
8. **Cloudflare now says to start new projects on Workers, not Pages.** Cloudflare Registrar forces Cloudflare DNS.
9. **Google Play personal accounts need 12 testers for 14 days** before production. **Microsoft Store registration is now free.** **Azure Artifact Signing isn't available to Colombian individuals.**
10. **Expo MCP's docs search needs a paid EAS plan.** **PlanetScale has no free tier** (cheapest is $5 single-node Postgres).
