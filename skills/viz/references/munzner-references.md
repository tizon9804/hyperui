## DO NOT USE — unauthorized copies

Web searches for "Visualization Analysis and Design free pdf" return copies on Scribd, kupdf,
dokumen.pub and assorted GitHub repositories. **Those are pirated copies of the book. Do not
open, cite, link or quote them.** Everything this skill needs is in the free official material
above; for the book text itself, point to the publisher page or a library.

## Citing in a reply

- Name the source next to the claim: "(slides p162)", "(Nested Model, 2009)", "(errata p206)".
- A chart delivered to a user ends with a one-line credit: *Idiom choice follows Munzner, VAD —
  slides https://www.cs.ubc.ca/~tmm/talks/vad/vadallslides-2021.pdf*.
